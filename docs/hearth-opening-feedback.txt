opportunity offers Inspect workshop without selecting villagers, issuing an order

gathering or Stores/carriers to fund the workshop, then select villagers and use

After useful edges are crafted, gather again. Only a load whose complete extraction
was observed with tools qualifies for the visit-local payoff message. Inspect a
finite deposit to see actual full-cycle samples. A full cycle lies between two
five-item deliveries by the same worker from the same source to the same store;
movement is classified before extraction phase. Travel, extraction and handling
sum to the observed simulation interval. Pause contributes no work time.
