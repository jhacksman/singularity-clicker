Lifecycle
One controller belongs to the current completion panel. Its reference is retained
synchronously so an in-flight initial inspection can be disposed immediately.
Every modal replacement, Close, Stay, Replay, native Escape/cancel/close and pagehide
uses idempotent disposal. A queued old close event cannot dispose a newly reopened
modal. Persisted pageshow resets the elapsed-time origin and remounts only the
currently open completion slot, with a fresh read and no automatic navigation.
The existing Cave view still owns its ordinary saves; widget inspection is read-only.
