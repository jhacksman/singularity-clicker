Official behavior checked independently

HTML's sequential focus navigation algorithm permits the UA to transfer focus
to its own controls when the document has no next candidate. That boundary is
distinct from modal background inertness: showModal makes connected document
nodes outside the topmost modal inert. Native modality does not establish the
harness's exact single-key last-to-first wrap.
https://html.spec.whatwg.org/multipage/interaction.html#sequential-focus-navigation
https://html.spec.whatwg.org/multipage/interaction.html#inert-subtrees

MDN documents that activeElement can be body/documentElement when no element is
focused, and that an active element does not itself prove the document has focus;
hasFocus supplies that separate observation. Neither an empty ID nor these API
rules identifies the actual destination in this failed run.
https://developer.mozilla.org/en-US/docs/Web/API/Document/activeElement
https://developer.mozilla.org/en-US/docs/Web/API/Document/hasFocus

Attempted disproof and calibration

- Perhaps the assertion proves a background interactive element received focus.
  No: an ID string is not an element identity. There is no captured background
  target, trusted focus event, click or resulting background action.
- Perhaps native dialog semantics require immediate DOM endpoint wrap, making
  this an unambiguous product defect. The authoritative UA navigation boundary
  contradicts that blanket assumption; native modality and browser controls are
  different scopes. A custom always-in-document loop would be an additional UX
  decision, not a correction demanded by this failed assertion alone.
- Perhaps the empty ID is sufficient to declare an ordinary URL-bar hop and
  mark the run successful. Also no: the identifying fields were not recorded.
  That causal attribution must remain provisional until an instrumented run.
- Perhaps removing endpoint assertions is sufficient. It would hide genuine
  background escape/actionability regressions. Replace the brittle endpoint
  assumption with stronger observed-state checks, not an unconditional exemption.
