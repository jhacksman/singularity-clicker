Lifecycle and ordering

disposeNavigation():128 clears the host reference before idempotent disposal.
openModal():137 disposes before replacing innerHTML, including Settings, recovery,
reset and external Cave-storage conflict replacements. closeModal():138 disposes
before closing. Close button, Stay and backdrop call that function. Native cancel
is prevented and routed through it, closing the earlier Escape bypass.

The native close listener at :139 guards the entire cleanup/unpause/render block
with !modal.open. Thus an older queued close notification cannot dispose a newly
opened panel or unpause a reopened modal. A genuine direct native close still
gets cleanup when the dialog remains closed. Replay's existing Cave mutation/save
and close run synchronously in one handler; there is no await between its mutation
and disposal that would allow an old pending inspection to act in between.
