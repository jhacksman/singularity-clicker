have no ordinary gathering receipts. Lines246–338 classify each actual actor
transition, reconcile per-source extraction and per-store receipts/pickups, retain
source reservation backing, and check global finite matter on every sampled save.

Construction pickup/receipt is checked at named actual edges, in five-item loads,
with the expected actor phase and origin. Sorted actor processing accounts for an
earlier delivery enabling a later builder's work in the same tick. Final24-work

checks require16 pickups,16 site receipts, exact60W20S and exactly24 installation
worker-seconds, both in aggregate and per-actor attribution. A tick cannot recruit;
that must occur at the separately audited UI command. Movement is bounded at
three cells per second. Named stores, global gathered counters and remaining
deposits are independently reconciled after each mixed-work step.

No obvious source-level infeasibility was found: initial material reserves cover
the sole outpost, food75 exceeds the sole25-food invitation, the fifth person is

at the food threshold is a reasonable fixture precondition, but remains something
execution must establish. It should fail visibly rather than silently change the
policy if that assumption is ever false.

   actual installation contribution separately. Preserve that distinction when
   presenting results; do not label all installationReady time as performed work.

2. The elapsed ranking compares these three fixed policies. It does not prove a
   globally optimal strategy or exclude other splits, recruitment counts or depot
   positions. Do not convert a fastest-of-three result into a universal rule.

3. Commands and evidence collection add no simulation time. These results can
   support physical reachability and policy tradeoffs, not human reaction time,
   real-time pacing, attention cost, fun or full-age balance. Standing-order
   behavior and native return-first remain part of each measured policy.

4. Verify the returned source/build binding, all three byte-identical starting
