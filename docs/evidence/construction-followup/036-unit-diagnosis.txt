Intrinsic index 20 is Map.prototype. The test snapshots each intrinsic using
Object.getOwnPropertyDescriptors and later deepStrictEqual-compares an entire
fresh descriptor object to the previous descriptor object (lines 551–558).
The log's actual and expected trees show the same Map descriptor keys, flags,
function labels, getter/setter labels and symbol descriptors; it does not show
a wood/stone/food property or another newly written property.

Map.prototype is the first object in this list with Symbol.toStringTag.
Object.getOwnPropertyDescriptors copies that key onto the descriptor-container
object; its value there is a newly allocated descriptor object, not the string
"Map". Thus both snapshot containers carry their own Symbol.toStringTag values,
and those values are distinct objects despite identical descriptor fields.
Whole-container deep equality is sensitive to this special branding property.
This matches the first failure occurring specifically at Map.prototype, after
indices 0–19 passed, while the printed descriptor trees appear identical.
