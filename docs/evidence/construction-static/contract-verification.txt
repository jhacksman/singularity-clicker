F2 closure — successor intent and custody are separate

The explicit cancellation order table preserves the baseline's meaningful Idle
sentinel. Baseline command() stores a loaded worker's new non-Move order in
u.next while retaining return context; receive() promotes u.next before start().
Baseline cancel() sets a matching queued target to {kind:'idle'}, not null.

For ordinary Gather cargo with next=Build(S), Cancel S now explicitly replaces
only that queued Build with Idle. The actual cargo retains its original receipt
authority and physical return. After receipt the worker idles; the superseded
Gather cannot resume merely because next was cleared to null. The same rule
prevents revival of an old Build(T) or another superseded current instruction.

For S-tagged cargo with current Build(S) and next=Gather, Build(T), or Idle,
Cancel S preserves that successor exactly. S's load returns and settles once,
then the accepted successor starts; it cannot be replaced with another S
recovery trip. Automatic recovery is limited to current Build(S) with no queued
successor. Current Move and held/manual Idle retain authority. Final cleanup
clears only obsolete S references, not unrelated orders or cargo ownership.
These rules resolve both critic witnesses and the null-versus-Idle trap without
claiming that the old engine already had the proposed construction defect.

Bounded material/source model

The active partition sources + staged + tagged cargo = recipe is consistent
with physically reserved source inventory: reservation changes availability,
pickup moves actual stock into cargo, and onsite receipt moves cargo into WIP.
Cancellation releases only unpicked reservations without adding stock; remaining
staged/cargo plus released/returned account for the same fixed recipe. Returning
active-site cargo increases receiving-store stock and its site reservation
together, so that return neither grants free goods nor demands another bill.
Cancelled-site receipt frees the actual goods exactly once. Recovery cargo is
not relabeled as gathering, transfer or outpost-reclaim production.

The clarified origins record is distinct from current sources: A pickup returned
to B creates no A delivery origin; a later B pickup actually delivered records
B. Origins sum to currently staged materials and decrease on recovery pickup.
Historical origins survive source retirement and must not be dereferenced as
live stores when the completed outpost obtains its claim. This clarifies the
already intended model; it does not revive the disproved source-history finding
or add an unbounded event journal.

New completion moves the full staged bill into spent only after the original
installation work. The unchanged costs are outpost 60W/20S with 24 worker-seconds
and workshop 40W/30S with 32; cargo capacity remains five, speed three cells/s,
and existing tool price/work/rate remains 4W/8S, 12, .45. Full delivery before
work is the declared versioned boundary, not a new per-load labor cost. A partial-
work cancellation physically recovers materials; performed work is not a refund
or transferable replacement-site progress. Funding remains opening-pool versus
post-opening local, with all construction and transfer reservations excluded
from availability to competing purchases.
